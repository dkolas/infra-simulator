

This doc sketches out my high level process when building this prototype.

* Bootstrap skills - pull in basic skills that are useful in developing. If this were a real project, I'd be importing these from somewhere else, but I used Claude to booststrap them to start from a clean repository.
* Iterate on the concept - Describe my thoughts in detail about what I wanted to build, but use Claude to poke holes, ask questions, and fill in gaps. Create docs/concept.md as an output. 
* Decide on technical frameworks and ask Claude to build scaffolding.
* Begin implementation. 
* Provide feedback & refine design. Look for issues.
* Publish app
